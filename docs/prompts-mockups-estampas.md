# Prompts dos mockups de estampa (ChatGPT)

Um prompt para cada tamanho e ângulo. A camisa sai **branca e lisa** de propósito: o Assistente pinta a camisa
na cor escolhida pelo usuário (as 18 cores da Algodão 30.1 Vortex) e aplica a estampa por cima, mantendo as dobras
e sombras do tecido. Assim bastam estas 32 fotos para todas as cores e todos os clientes.

## Como gerar

1. Abra **uma conversa nova para cada tamanho**, para manter a mesma pessoa nos 4 ângulos.
2. Cole primeiro o prompt de **Frente**. Depois cole os outros três na **mesma conversa**, começando com:
   *"Same person, same t-shirt, same shorts, same lighting and framing as the previous image."*
3. Baixe as imagens em PNG ou JPG, sem cortar. Nomeie como `comum-M-frente.png`, `baby-P-costas.png` etc.
4. Confira se a camisa ficou lisa (sem estampa ou logo) e se o enquadramento ficou do queixo à coxa.

Biotipos: cada tamanho usa um corpo realista para aquele tamanho, sem caricatura. No tipo comum, se quiser
uma modelo mulher, troque o início da descrição por *"a woman with a ... build"* mantendo o tamanho.
