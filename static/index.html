        Publicar template

        Arraste o .zip do template.

        O sistema valida o contrato, roda as checagens do HyperFrames e gera a capa antes de publicar.

        Pasta do template compactada · template.json + index.html + assets/

        Como criar um template

        1. Baixe o kit e descompacte na pasta de skills do Claude (~/.claude/skills/). Uma vez: npm install na pasta motor do kit.
        2. Crie com o seu Claude. Peça: “crie um template de ofertas a partir desta arte”. Ele cria em 1280×720 e valida com as ferramentas do kit.
        3. Compacte a pasta do template em .zip.
        4. Publique aqui. Se o id já existir, a versão anterior é guardada.
